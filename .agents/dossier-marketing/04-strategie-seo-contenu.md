## Plan de contenu éditorial — 12 semaines

### Mois 1 — Fondations SEO

**Semaine 1**
- Article : *"Que boire quand on ne boit pas d'alcool ? 7 alternatives au vin pour une vraie expérience gustative"*
  - Cible : "que boire quand on ne boit pas d'alcool" (2 000–5 000 /mois)
  - Angle : éducatif, non-commercial, Osan cité comme découverte finale
  - Format : guide 1 500 mots, structured data FAQ

**Semaine 2**
- Article : *"Pourquoi les vins sans alcool déçoivent (et ce qu'il faut boire à la place)"*
  - Cible : "vin sans alcool goût" + "alternative vin sans alcool"
  - Angle : critique informée, positionne Osan sans l'imposer
  - Format : 1 200 mots + comparatif visuel

**Semaine 3**
- Page pilier : *"L'accord mets-boissons sans alcool : le guide complet"*
  - Cible : "accord mets boisson sans alcool" — requête à fort potentiel
  - Angle : référence éducative, Osan comme outil de l'accord
  - Format : 2 500 mots, tableaux d'accords, Schema FAQ

**Semaine 4**
- Article : *"Dry January : nos 5 boissons préférées pour tenir le mois sans ennui"*
  - Cible : Dry January, saisonnier (pic en décembre–janvier)
  - À publier en décembre pour capter le trafic janvier

## SEO technique — Checklist prioritaire

- [ ] Balises title et meta description optimisées sur toutes les pages produit
- [ ] Schema markup `Product` sur les fiches produits (price, availability, rating)
- [ ] Schema markup `Article` sur les articles de blog
- [ ] Schema markup `FAQ` sur les articles informationnels
- [ ] Fichier `sitemap.xml` à jour et soumis à Google Search Console
- [ ] Core Web Vitals : LCP < 2.5s, CLS < 0.1, FID < 100ms
- [ ] Images optimisées : WebP, alt text descriptifs ("Osan Shiso Basilic bouteille 75cl boisson botanique bio")
- [ ] Liens internes entre articles de blog et pages produit
- [ ] Version mobile parfaite — 70 %+ du trafic arrivera sur mobile
