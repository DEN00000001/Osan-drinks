# Sano Sano — Copywriting Project

## Structure du projet

```
sano-sano-copywriting/
├── README.md                          (ce fichier)
├── website/                           # Contenu pour le site web
│   ├── homepage.md                    # Texte homepage
│   ├── product-pages.md               # Fiches produits
│   ├── about.md                       # Qui sommes-nous
│   └── emails.md                      # Emails marketing
├── ads/                               # Copy pour publicités
│   ├── social-media.md                # Posts Instagram, TikTok, LinkedIn
│   ├── google-ads.md                  # Search & Display ads
│   └── print.md                       # Brochures, press kits
├── campaigns/                         # Campagnes thématiques
│   └── launch.md                      # Campagne de lancement
└── assets/                            # Assets bruts
    └── brand-guidelines.md            # Tone, style guide
```

## Processus de copywriting

1. **Product Marketing Context** ✓ (voir `../sano-sano-context.md`)
2. **Copy generation** → utiliser les skills: `copywriting`, `ad-creative`, `content-strategy`
3. **Review & refinement** → vérifier cohérence, tone, CTA
4. **AB testing setup** → si campagnes multi-variantes
5. **Publishing** → intégration web, emails, ads

## Skills disponibles
- `copywriting` — écriture générale
- `ad-creative` — créatif publicitaire
- `content-strategy` — stratégie de contenu
- `social-content` — posts réseaux sociaux
- `email-sequence` — séquences d'emails marketing
- `page-cro` — optimisation conversion landing pages
- `ab-test-setup` — setup A/B testing
